# 0001 — Name: Latent (显影)

- Status: accepted
- Date: 2026-11-25
- Decision owner: HugoXK
- Repository: `HugoXK/latent`

## Context

The product develops an incomplete idea into a version a person can question,
test and act on. It is explicitly **not** an idea generator. The name must:

1. be short and pronounceable in Chinese and English;
2. encode **development of something already present**, not creation;
3. work as a Chinese product name and a Chinese tagline;
4. be plausible as a `.dev` / `.ai` / `.ink` domain and a GitHub repository;
5. not encode "AI", "note", "prompt" or "idea", so the product can extend;
6. not collide with a well-known product in the same category.

The product is a sibling of **Fledge** (羽巢) and **Janus**, and should feel like
the same family without copying either name.

## Candidates

| Name | Meaning | Strength | Risk |
|---|---|---|---|
| **Latent** / **显影** | A latent image is on the film before it is visible; the developer brings it out | Exactly "develop, don't generate"; technical double meaning (latent space); a verb in the UI | "latent" can read as "hidden/dormant"; "显影" has a medical-imaging association |
| **Tessera** / **缀合** | A tessera is one tile of a mosaic; 缀合 is the philological reconstruction of fragments | Precise "fragments → whole"; scholarly depth | "缀" is less familiar to type; Tessera is less pronounceable in Chinese |
| **Asterism** / **星图** | A pattern you draw between scattered stars that is not an official constellation | Romantic, visual, "your own pattern" | Leans "organise", not "verify" |
| **Reverie** / **续梦** | Continue an unfinished dream | Warmest, closest to the original metaphor | Sounds like a sleep or meditation app |
| **Glean** / **拾穗** | Picking up the grain left after harvest (Millet's *The Gleaners*) | Humane, humble | `Glean` is an established enterprise-search product |

## Decision

**Latent** (Chinese: **显影**).

- English tagline: **Don't generate. Develop.**
- Chinese tagline: **不替你造，只帮你显。**
- Product verb: *develop an idea* — capture a fragment, develop it into hypotheses
  and gates, compile a brief.
- Visual language: a film frame and a rising latent dot, not a robot and not a
  lightbulb. The mark is a rounded square (the frame) with a circle inside (the
  latent image) and a horizontal line (the developing pass).
- The two READMEs, the wordmark and the UI use the photography metaphor sparingly:
  *latent*, *develop*, *fragment*, *brief*. Not every sentence.

## Consequences

- The product never claims to "generate" an idea. The copy says **develop**,
  **reconstruct**, **verify**, **compile**.
- The user remains the author. The system is the darkroom.
- The name does not encode a domain, a model or a task, so the same core can serve
  iGEM, research proposals and startup ideas without a rename.
- Domain candidates: `latent.ink`, `getlatent.dev`, `latentlab.ai`. Verify
  availability and trademark class 9/42 before purchase. If a conflict appears, the
  first fallback is **Tessera** (缀合), because the schema already uses
  "fragment" and "stitch" language.
- The repo is `HugoXK/latent`; the Chinese display name is 显影.
