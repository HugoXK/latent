safety: enforce the BSL and dual-use classifier before iGEM reconstruction

The iGEM pack runs the rule-based classifier on the fragment and string
constraints before the reconstructor. Select agents, toxins and enhancement
language are refused; a BSL-2 pathogen requires BSL-2 clearance. The refusal is a
typed error (CLI exit 1, API 422) and the audit event records category/bsl only,
never the fragment text or matched terms.
