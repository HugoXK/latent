ledger: wire existence and vertical-rule validators and add an audit view

`runExistenceValidator` passes when there are no external objects and fails closed
when a source-bearing claim has no provider; a missing object demotes a verified
claim. `compileIgemBrief` now records the iGEM rules freshness, and a failed
validator blocks the brief. `latent ledger audit` shows every claim, source, span
and validator; the Markdown export includes sources and spans.
