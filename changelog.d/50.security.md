api: require a bearer token, enforce scopes, CSRF origin and rate limits

Every `/v1` route now needs a scoped bearer token; the local token is read from
`LATENT_AUTH_TOKEN`, `LATENT_AUTH_TOKEN_FILE` or a generated `0600`
`data/runtime/auth-token`. Non-loopback Host and cross-origin requests are refused,
rate limits return `429 RATE_LIMITED`, oversized bodies return `413 BODY_TOO_LARGE`,
and `/healthz`/`/readyz` stay public.
